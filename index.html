CSS Grid Layout

Grid lays out items in rows and columns at the same time. You define the tracks on the container, then place items into the cells and areas they create, with no floats, positioning or extra wrapper markup.

Grid Terminology

Once you give an element display: grid, it becomes the grid container and its direct children become grid items.
Lines divide the grid into tracks, and tracks cross to form cells and areas.

When to Use Grid ?

Flexbox works in one direction and sizes from the content out. Grid works in two directions and sizes from the layout in.
Use grid when rows and columns need to line up.

Flexbox: one dimension

1234

Each line sizes its own items. Columns do not line up across lines.

Grid: two dimensions

123456

Rows and columns are shared, so every item lines up both ways.

Explicit vs Implicit Grid

Tracks you define with grid-template-* form the explicit grid. When there are more items than cells, the browser adds implicit tracks, sized by grid-auto-rows / grid-auto-columns.

12345678
explicit rows (50px)implicit row (grid-auto-rows: 36px)

Grid Container Properties

display, grid-template-columns / rows, grid-template-areas, grid-template, gap, justify-items, align-items, justify-content, align-content, grid-auto-rows / columns, grid-auto-flow, grid

{display} // Values: grid | inline-grid

grid makes a block-level grid container. inline-grid makes one that sits inline with the surrounding text.

Display Grid Example:

{grid-template-columns / rows} // Default: none

Defines the explicit columns and rows as a space-separated list of track sizes. Any length, percentage, fr or sizing function works.

Grid Template Columns Example:

{grid-template-areas} // Default: none

Names areas of the grid with strings, one string per row. Items then claim an area with grid-area: name. A . leaves a cell empty.

Grid Template Areas Example:

{grid-template} // Default: none

Shorthand for grid-template-rows, grid-template-columns and grid-template-areas. Each row's size follows its area string, and column sizes come after the slash.

  .page {
    grid-template:
      "header header" 60px
      "sidebar main"  1fr
      "footer footer" 40px
      / 200px 1fr;
  }

Grid Template Example:

{gap} // Default: 0

Sets the space between tracks. Shorthand for row-gap and column-gap. Gaps only go between tracks, never at the outer edges.

Grid Gap Example:

{justify-items} // Default: stretch

Aligns every item inside its cell along the inline (row) axis.

Justify Items Example:

{align-items} // Default: stretch

Aligns every item inside its cell along the block (column) axis.

  • place-items: center sets align-items and justify-items in one go.

Align Items Example:

{justify-content} // Default: normal

When the tracks are smaller than the container, this moves the whole grid along the inline axis. It aligns the tracks, not the items.

Justify Content Example:

{align-content} // Default: normal

Same as justify-content, but moves the rows along the block axis. It only has an effect when the container is taller than its rows.

  • place-content sets align-content and justify-content together.

Align Content Example:

{grid-auto-rows / columns} // Default: auto

Sizes the implicit tracks, the ones the browser creates when items land outside the explicit grid.

Grid Auto Rows Example:

{grid-auto-flow} // Default: row

Controls how the auto-placement algorithm fills the grid: row by row, or column by column. dense back-fills holes left by larger items.

Grid Auto Flow Example:

{grid} // Default: none

Shorthand for the explicit properties (grid-template-*) and the implicit ones (grid-auto-*) in one declaration.

  • It resets every template and auto property it does not set. Prefer grid-template unless you need auto-flow.
  .feed {
    /* rows / columns */
    grid: auto-flow 120px / repeat(3, 1fr);
  }

Sizing Toolkit

fr, fr vs %, repeat(), minmax(), auto-fill vs auto-fit, min-content / max-content / fit-content()

{fr} // fraction of free space

The fr unit shares out the space left after fixed tracks and gaps are taken. 1fr 1fr 2fr splits it 25% / 25% / 50%.

Fraction Unit Example:

{fr vs %} // why fr wins

% is measured against the whole container and ignores gap. fr only shares the space left after gaps and fixed tracks.

  • 1fr instead of calc((100% - 2 * gap) / 3).
  • Mixes with fixed sizes: 200px 1fr, no calc().
  • fr rows work without a fixed container height.

fr vs % Example:

{repeat()} // repeat(count, tracks)

Repeats a track list instead of writing it out. The pattern can hold more than one track.

Repeat Function Example:

{minmax()} // minmax(min, max)

Sets a size range for a track: never smaller than min, never larger than max.

  • minmax(200px, 1fr): at least 200px, then share free space.
  • minmax(0, 1fr): a column that is allowed to shrink below its content.
  • minmax(100px, auto): a row at least 100px tall that grows with content.

Minmax Function Example:

{auto-fill vs auto-fit} // repeat(auto-fill | auto-fit, size)

Both create as many tracks as fit in the container. With few items, auto-fill keeps the empty tracks and auto-fit collapses them, so the items stretch.

Auto Fill vs Auto Fit Example:

{content sizing} // min-content | max-content | fit-content()

Size a track from what is inside it.

  • min-content: as narrow as the longest word.
  • max-content: as wide as the content on one line.
  • fit-content(150px): max-content, capped at 150px.

Grid Items Properties

grid-column-start / end, grid-column / grid-row, grid-area, justify-self, align-self, overlap & z-index

{grid-column-start / end} // Default: auto

Places an item by naming the grid lines it starts and ends on. grid-row-start and grid-row-end do the same for rows.

Grid Line Placement Example:

{grid-column / grid-row} // Default: auto

Shorthands for start / end. Use span n to cover n tracks, and negative numbers to count lines from the end.

  • grid-column: 1 / -1 stretches across every explicit column.

Span and Negative Lines Example:

{grid-area} // Default: auto

Either puts the item into a named area from grid-template-areas, or works as a shorthand for all four lines.

  • grid-area: main;
  • grid-area: 1 / 2 / 3 / 4; is row-start / column-start / row-end / column-end.

Grid Area Example:

{justify-self} // Default: auto

Aligns a single item inside its cell along the inline axis, overriding the container's justify-items. Unlike flexbox, grid has a working justify-self.

Justify Self Example:

{align-self} // Default: auto

Aligns a single item inside its cell along the block axis, overriding the container's align-items.

  • place-self sets align-self and justify-self together.

Align Self Example:

{overlap & z-index} // Default: auto

Items can share cells. Later items paint on top, and z-index works on grid items without setting position.

So, how does basic grid work?
it's just 'display: grid', but it comes with useful default properties

1

This paragraph is the second grid item. With no columns defined, it sits in its own row under the first item, like a block element.

3
  1. once you have given display: grid, the grid has a single column track, so items stack like blocks
  2. default grid-auto-flow: row, places each item in the next cell, filling rows from left to right
  3. default grid-auto-rows: auto, creates an implicit row for each item, sized to its content
  4. default justify-items / align-items: stretch, makes items fill their cells
  5. default gap: 0, and margins of grid items never collapse into each other

Useful Tips & Tricks

Responsive cards, no media queries

Cards wrap into as many columns as fit, each at least 240px wide, and stretch to fill the row.

  .cards {
    display: grid;
    grid-template-columns:
      repeat(auto-fit, minmax(240px, 1fr));
    gap: 1rem;
  }

Responsive card grid

Page layout with named areas

Redraw the layout at a breakpoint by changing only the area strings. The HTML stays the same.

  .page {
    display: grid;
    grid-template-areas:
      "header" "main" "sidebar" "footer";
  }
  @media (min-width: 768px) {
    .page {
      grid-template-columns: 220px 1fr;
      grid-template-areas:
        "header  header"
        "sidebar main"
        "footer  footer";
    }
  }

Responsive page layout

Stack layers without position

Put the image and the caption in the same cell. No absolute positioning, and the container still sizes to its tallest layer.

  .hero {
    display: grid;
  }
  .hero > * {
    grid-area: 1 / 1;
  }
  .hero .caption {
    align-self: end;
  }

Overlay text on an image

Center anything

Two lines, both axes. Works for one child or a stack of children.

  .center {
    display: grid;
    place-items: center;
  }

Center with place-items

Full-bleed with named lines

Name the lines around a centered content column. Text stays readable, and any child can break out to the full width.

  .article {
    display: grid;
    grid-template-columns:
      [full-start] 1fr
      [content-start] min(65ch, 100% - 2rem)
      [content-end] 1fr [full-end];
  }
  .article > * { grid-column: content; }
  .article > .bleed { grid-column: full; }

Full-bleed article layout

Line up card content with subgrid

Each card spans three rows and reuses the parent's row tracks, so titles, text and buttons line up across cards even when the text length differs.

  .cards {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
  }
  .card {
    grid-row: span 3;
    display: grid;
    grid-template-rows: subgrid;
  }

Aligned cards with subgrid

Gallery that fills the gaps

Mix wide and tall tiles and let dense pull smaller items back into the holes.

  .gallery {
    display: grid;
    grid-template-columns:
      repeat(auto-fill, minmax(150px, 1fr));
    grid-auto-rows: 150px;
    grid-auto-flow: dense;
  }
  .wide { grid-column: span 2; }
  .tall { grid-row: span 2; }

Common gotchas

  1. 1fr is minmax(auto, 1fr), so a long word or wide image can push the column wider. Use minmax(0, 1fr) to let it shrink.
  2. auto-fill keeps empty tracks, auto-fit collapses them. With few items they look very different.
  3. Lines are numbered from 1, so a 3-column grid has lines 1 to 4. grid-column: 1 / 3 covers two columns, not three.
  4. Each named area must form a rectangle. An L-shaped area makes the whole grid-template-areas declaration invalid.
  5. Only direct children are grid items. Use subgrid for nested alignment.
  6. Line placement, dense and order change visual order only. Keyboard and screen reader order still follow the DOM.
