# CSS Grid - Presentation
Presentation about CSS Grid Layout
https://naren-irain.github.io/grid-presentation/#/

Companion to the [Flexbox presentation](https://naren-irain.github.io/flexbox-presentation/#/).

## Topics discovered
* Grid basics: terminology, grid vs flexbox, explicit vs implicit grid
* Grid container properties
* Sizing toolkit: `fr`, `repeat()`, `minmax()`, `auto-fill` / `auto-fit`, content sizing
* Grid item properties
* Tips & tricks and common gotchas

## Demos
Demos run inside the deck, with no CodePen. Each demo is a
`<div class="gridPreview" data-preview="key">` in `index.html`, rendered by
`assets/js/preview.js` from the matching entry in `GRID_PREVIEWS`: buttons to
switch values, the live grid, and the CSS for the current state.
